# CrowTV, version web

Version web de CrowTV, un suivi de séries, films, animés et manhwas. Ce dépôt ne contient que la version construite, publiée par GitHub Pages.

- Tes données restent dans ton navigateur, sans compte. Elles ne sont pas partagées avec l'app Android.
- Séries et films passent par le relais de CrowTV, qui garde la clé TMDB côté serveur : aucune clé n'est dans ce site.
- Pas de notifications ni de widget dans cette version.

This product uses the TMDB API but is not endorsed or certified by TMDB.
